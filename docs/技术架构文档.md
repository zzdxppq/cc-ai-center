# KCZJ AI Center 技术架构详细文档

## 1. 项目概述

**项目名称**: kczj-ai-center  
**项目描述**: 基于 Spring Cloud 微服务架构的 AI 教育平台  
**版本**: 3.0  
**Java 版本**: 21  
**构建工具**: Maven  
**编码**: UTF-8

---

## 2. 项目结构

### 2.1 模块划分

本项目采用多模块 Maven 聚合项目结构，主要模块如下：

```
kczj-ai-center/
├── kczjplane-common/              # 公共基础模块
├── kczj-auto-tool/                 # 代码生成工具模块
│   ├── kczj-plane-auto-annotations/
│   └── kczj-plane-auto-generator/
├── hnerplane-user-center/         # 用户中心服务
│   ├── kczj-plane-user-core/      # 用户核心业务模块
│   ├── kczj-plane-user-open/       # 用户开放接口模块
│   ├── kczj-plane-user-own/       # 用户自有接口模块
│   └── kczj-plane-user-job/       # 用户定时任务模块
├── hnerplane-appserve/             # 应用服务
│   ├── hnerplane-appserve-core/   # 应用核心业务模块
│   ├── hnerplane-appserve-open/    # 应用开放接口模块
│   └── hnerplane-appserve-own/    # 应用自有接口模块
└── hnerplane-gateway/              # API 网关服务
```

### 2.2 模块职责说明

| 模块 | 职责 | 端口 |
|------|------|------|
| kczjplane-common | 公共组件、工具类、统一配置 | - |
| kczj-plane-user-open | 用户中心开放 API | 9001 |
| kczj-plane-user-own | 用户中心自有 API | - |
| kczj-plane-user-job | 用户中心定时任务 | - |
| hnerplane-appserve-open | 应用服务开放 API | - |
| hnerplane-appserve-own | 应用服务自有 API | - |
| hnerplane-gateway | API 网关、路由转发 | - |

- **主数据库**: MySQL 8.0+

### 5.2 数据库连接配置

- **开发环境**: `jingshi_ai_db_test`

- **字符集**: UTF-8

### 6.1 缓存类型

1. **分布式缓存**: Redis（Redisson）

## 15. API 文档

### 15.1 文档工具

- **Knife4j**: OpenAPI 3.0 文档生成
- **SpringDoc**: OpenAPI 规范实现
- **访问路径**: `/doc.html`（开发/测试环境）

### 15.2 文档规范

- 使用 OpenAPI 3.0 注解（`@Operation`、`@Schema` 等）
- 所有接口必须编写文档说明
- 入参和返回值必须定义对象，禁止使用 Map

---

## 16. 统一规范

### 16.1 返回值规范

- **统一返回对象**: `R<T>`
- **使用位置**: 仅在 Controller 层使用 `R.ok()`
- **异常处理**: 统一异常处理，抛出 `ClientException` 或 `BusinessException`

### 16.2 JSON 处理规范

- **JSON 库**: Jackson（全局配置）
- **日期格式**: 毫秒时间戳（自动转换）
- **空值处理**: Controller 返回值包含所有字段，工具类 null 值不序列化

### 16.3 代码规范

- **事务注解**: ServiceImpl 层必须添加 `@Transactional`
- **SQL 规范**: 
  - 禁止在 XML 中编写复杂 SQL（除非必要）
  - 尽量单表查询，做好索引
  - 使用方法引用而非字符串变量名
- **分页规范**: 
  - 统一使用 PageHelper
  - 必须有 ORDER BY 且有索引

### 16.4 配置规范

- **配置文件命名**: `dev` / `test` / `prod`
- **分支命名**: `dev` / `test` / `master`

## 21. 性能优化

### 21.1 数据库优化

- **索引优化**: 分页查询必须有索引

### 21.3 异步处理
